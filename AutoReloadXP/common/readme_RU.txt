AutoReloadXP — автоматическая прокачка навыка перезарядки.

Нажмите F9, чтобы включить или выключить мод. Он выбирает пригодное
огнестрельное оружие с максимальной вместимостью из инвентаря, включая
вложенные контейнеры. Для оружия со съёмным магазином необходим совместимый
магазин; для любого оружия нужен хотя бы один отдельный подходящий патрон.
Сломанное и заклинившее оружие не используется.

Персонаж многократно разряжает и заряжает выбранный магазин или оружие со
встроенным магазином. Для встроенного магазина оружие берётся в основную руку.
При извлечении установленного магазина штатное действие игры также требует
взять оружие в руку. Извлечённый магазин остаётся в инвентаре. Патроны и
предметы из вложенных контейнеров могут быть перемещены в основной инвентарь.

Для диагностики в игровой Lua-консоли выполните AutoReloadDebug(). Результат
выбора и причины исключения предметов выводятся в игровой журнал.

Если подходящих предметов нет, действие прервано или предмет стал недоступен,
мод отключается и сообщает причину. При выключении по F9 уже запущенное
игровое действие не отменяется.

Для отмены игрового действия нажмите "Пробел", это вызовет немедленную рекцию персонажа.

Каталог common требуется для структуры мода Project Zomboid Build 42.

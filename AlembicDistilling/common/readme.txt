Alembic Distilling adds a portable copper alembic for Project Zomboid Build 42.

Assemble the alembic from a vanilla kettle, rubber hose, metal pipe and funnel.
Fill it with one supported alcoholic fluid, heat it in a compatible furnace or
fire, then use the "Distill in Portable Alembic" recipe. The calculation uses
the actual fluid amount and alcohol strength with 75 percent efficiency.

The first release includes only the portable alembic. Steel and stationary
stills remain planned features.

Loot Tracker запоминает литературу, VHS-кассеты, CD-диски и инструменты из контейнеров, чтобы отмечать еще не найденные предметы.

Для использования мода нажмите правой кнопкой мыши на контейнер (шкаф, ящик, сумка и т.д.) и выберите опцию "Отследить предметы" в контекстном меню. Это позволит моду запомнить все содержимое контейнера.

Для сброса всех данных нажмите правой кнопкой мыши и выберите опцию "Сбросить список предметов" в контекстном меню.

При смерти персонажа данные надо собрать заного.

Каталог common требуется для структуры мода Project Zomboid Build 42.

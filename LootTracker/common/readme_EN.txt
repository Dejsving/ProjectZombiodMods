Loot Tracker remembers literature, VHS tapes, CDs, and tools from containers to mark items that haven't been found yet.

To use the mod, right-click on a container (cabinet, drawer, bag, etc.) and select "Track Items" in the context menu. This will allow the mod to remember all the contents of the container.

To reset all data, right-click and select "Reset Items List" in the context menu.

When your character dies, the data needs to be collected anew.

The common directory is required for the Project Zomboid Build 42 mod structure.
